# Source index

- [RFC 9110 HTTP Semantics](https://www.rfc-editor.org/rfc/rfc9110) — normative reference for HTTP method, status, request and representation semantics.
- [RFC 9457 Problem Details](https://www.rfc-editor.org/rfc/rfc9457) — standard format for machine-readable HTTP error details when adopted by the API.
- [OWASP API Security](https://owasp.org/www-project-api-security/) — API-specific security risks and controls; use the current project material rather than treating the list as exhaustive.
- [Google SRE: Handling Overload](https://sre.google/sre-book/handling-overload/) — supports bounded service behavior, overload handling and avoiding retry amplification.
- [WHATWG Fetch](https://fetch.spec.whatwg.org/) — relevant only when the backend boundary or implementation uses Fetch semantics.

Research boundary: the actual authentication model, framework lifecycle, compatibility policy and API schema are repository facts. Standards and guidance cannot prove the live behavior of a service.
