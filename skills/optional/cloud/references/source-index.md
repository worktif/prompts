# Source index

- [AWS Well-Architected Framework](https://docs.aws.amazon.com/wellarchitected/latest/framework/welcome.html) — AWS architecture questions across operational excellence, security, reliability, performance efficiency, cost optimization and sustainability.
- [AWS Reliability Pillar](https://docs.aws.amazon.com/wellarchitected/latest/reliability-pillar/welcome.html) — supports resilient architecture, change management, recovery testing and failure management for AWS workloads.
- [AWS Security Pillar](https://docs.aws.amazon.com/wellarchitected/latest/security-pillar/welcome.html) — supports identity, detection, infrastructure protection, data protection, incident response and application security review.
- [AWS least privilege](https://docs.aws.amazon.com/wellarchitected/latest/security-pillar/sec_permissions_least_privileges.html) — supports granting only required actions on required resources under required conditions.
- [AWS permission guardrails](https://docs.aws.amazon.com/wellarchitected/latest/security-pillar/sec_permissions_define_guardrails.html) — supports limiting the maximum permissions that can be granted, not only reviewing individual policies.
- [AWS IAM policy evaluation logic](https://docs.aws.amazon.com/IAM/latest/UserGuide/reference_policies_evaluation-logic.html) — supports analyzing identity, resource, boundary and organization policy interactions.

Research boundary: these sources are AWS-specific. GCP, Azure and other providers require their current primary documentation; no source proves live resources, permissions or deployment health without querying the target environment.
