Prepare the architectural specification for the upcoming epic before any implementation starts.

Your task is to define the code-level architecture using object-oriented programming as the default implementation model.

Generics are a core requirement. Use generic contracts where they improve type safety, extensibility, substitution, and correctness of the design.

Standalone functions are allowed only when they are pure stateless utilities or when a specific part of the solution is explicitly designed as functional programming.

You MUST:

1. Define the architectural model for the epic.
2. Identify the required classes, interfaces, abstract types, generic contracts, and responsibility boundaries.
3. Explain how the selected abstractions interact.
4. Use design patterns only when they solve a concrete architectural responsibility.
5. Treat Factory and Singleton as exceptional patterns requiring explicit justification.
6. Produce a specification that prevents ad-hoc implementation.

You MUST NOT:

1. Start implementation before the architecture is specified.
2. Replace object-oriented structure with loose standalone functions.
3. Use pattern names without proving their role in the epic.
4. Introduce Factory, Singleton, global state, or service-locator behavior by default.
5. Produce generic best-practice commentary.

Final output must include:

* architectural model;
* core abstractions;
* generic contracts;
* selected and rejected patterns;
* implementation boundaries;
